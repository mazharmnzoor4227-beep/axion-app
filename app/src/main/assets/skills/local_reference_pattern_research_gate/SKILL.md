# Reference pattern research gate

## Research before building

- Research real open source projects before building a site or hub that copies a known pattern, and verify each project license in its license file rather than trusting a description alone.

- Record each candidate with its repository, its license, and whether its icon or artwork is usable, and drop any candidate that has no clean license for the intended use.

- Open the real professional pattern sites yourself and describe their layout in plain terms, including tile density, categories, search, and the game or product page shape, without copying their code, artwork, logos, or copy.

- Separate items that can use real licensed code and artwork from items that need original similar artwork, and name any proprietary item that must be replaced rather than lifted.

- Name any pattern measurement you have not checked as unverified, and do not claim a build matches a reference you have not measured.

## Get approval on the shortlist

- Present the research as a shortlist or plan before building, with each item, its license, and what will be original rather than copied.

- Wait for the user to approve the shortlist or plan, and build only the approved items in the approved layout.

- Do not add a dropped item back under a new name, and do not widen the build to items the user has not approved.

## Stop after a rejection

- Stop building and stop redesigning on guesswork after the user rejects a build as cartoon like or rejects its whole interface.

- Ask the user for a screenshot of the reference as seen on their phone or for a chosen sample direction, and resume only after the user gives that choice.

- Fix only the items the user named in a rejection, and present the fix for approval before rebuilding the whole interface.

## Available connectors

- Use `muse.connector_search` to find other connectors and `muse.skill_search` to find related skills.

- If nothing here fits, look on the web for a maintained API or MCP server and set it up with [Custom Connectors and MCPs](/opt/muse/skills/custom-connector-setup/SKILL.md), or build a custom connector.

## Alternatives for better results

- Ask the user to pick one approved sample direction before a redesign, rather than offering another full redesign from your own taste.

- Build a small preview of one tile or one page from the approved shortlist first, and get approval on that preview before building the full hub.
