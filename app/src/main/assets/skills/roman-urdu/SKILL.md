# Roman Urdu writing

- Write the way people in Karachi/Lahore actually text: "Aapka order confirm ho gaya hai", not formal Hindi.
- Mix common English words naturally (order, delivery, price, skin, offer).
- Short lines, friendly, respectful ("aap"), no over-promising.
- For product copy: benefit first, then key ingredients, then how to use, then price/COD/delivery line.
- For captions: hook line, 2–3 benefit lines, CTA ("Order ke liye DM karein / link bio mein"), 8–15 relevant hashtags.
